# Сайт Kapsik: политика конфиденциальности

`privacy/index.html` — политика конфиденциальности на английском и русском на одной странице. Ссылка `…/privacy/` открывает английскую версию, `…/privacy/#ru` — русскую.

Это шаблон по требованиям Google Play, а не юридическая консультация.

## 1. Заполнить три поля

Найдите и замените в файле (каждое встречается несколько раз):

| Поле | Чем заменить |
|---|---|
| `[[DEVELOPER_NAME]]` | Имя разработчика **точно как на странице приложения в Google Play**. Для личного аккаунта это ваше имя латиницей из Play Console. Google проверяет, что это имя есть в политике. |
| `[[EMAIL]]` | Почта для связи, та же, что в Play Console. Её увидят все, поэтому удобно завести отдельный ящик для приложений. |
| `[[DATE]]` | Дата публикации, например `November 3, 2026` в английской части и `3 ноября 2026 г.` в русской. |

Проверка, что ничего не осталось:

```bash
grep -n "\[\[" kapsik-site/privacy/index.html
```

## 2. Опубликовать на GitHub Pages (бесплатно)

1. Создайте на GitHub **публичный** репозиторий, например `kapsik-site`.
2. Загрузите в него содержимое папки `kapsik-site`: папку `privacy` с `index.html` внутри.
3. В репозитории: Settings → Pages → Build and deployment → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту страница откроется по адресу `https://<ваш-логин>.github.io/kapsik-site/privacy/`.

Требования Google к ссылке: страница открыта для всех, без входа, без ограничений по странам, не PDF и не редактируемый документ. GitHub Pages всё это выполняет.

Позже можно купить домен `kapsik.app` и подключить его в том же разделе Pages (Custom domain), тогда адрес будет `https://kapsik.app/privacy/`. Если адрес поменяется, обновите ссылку в Play Console, в RuStore и в приложении.

## 3. Куда вставить ссылку

- **Play Console:** «Контент приложения» (App content) → «Политика конфиденциальности».
- **RuStore:** поле политики конфиденциальности в карточке приложения.
- **В приложении:** пункт «Политика конфиденциальности» в настройках и ссылка на экране согласия на отчёты о сбоях. Google требует ссылку и в консоли, и внутри приложения.

## 4. Когда обновлять политику

Политика должна совпадать с тем, что реально делает приложение. Обновите её (и дату), если:
- выберете Sentry вместо Firebase Crashlytics или добавите любой другой сервис;
- подключите RevenueCat или оплату через RuStore, ЮKassa или Робокассу;
- добавите бэкап в Google Drive, синхронизацию или режим для близких — всё, что отправляет данные с устройства;
- добавите новое разрешение.

Что приложение должно делать, чтобы политика была правдой, и ответы для формы Data safety — в `plans/meds-mvp.md`, раздел «Политика конфиденциальности и Data safety».
